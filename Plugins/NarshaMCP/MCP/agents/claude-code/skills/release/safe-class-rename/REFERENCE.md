# Safe Class Rename - Technical Reference

## CoreRedirects System

### What are CoreRedirects?

CoreRedirects is Unreal Engine's built-in mechanism for handling asset references when classes, properties, or packages are renamed. When a Blueprint references a C++ class that has been renamed, CoreRedirects tells the engine where to find the new class.

### INI Syntax

```ini
[/Script/Engine.Engine]
+ClassRedirects=(OldName="LCPlayerController",NewName="LCNewController")
```

**Important**: Class names in CoreRedirects use the **stripped** prefix (without A/U/F/I/E/T):
- `ALCPlayerController` -> `LCPlayerController` (A prefix stripped)
- `UMyComponent` -> `MyComponent` (U prefix stripped)

### Prefix Stripping Logic

```python
def strip_class_prefix(class_name: str) -> str:
    """Remove UE class prefix for CoreRedirects."""
    prefixes = ['A', 'U', 'F', 'I', 'E', 'T']
    for prefix in prefixes:
        if class_name.startswith(prefix) and len(class_name) > 1:
            # Check if second character is uppercase (valid prefix)
            if class_name[1].isupper():
                return class_name[1:]
    return class_name
```

### CoreRedirects File Location

```text
{ProjectRoot}/Config/DefaultEngine.ini
```

The tool appends to the `[/Script/Engine.Engine]` section. If the section doesn't exist, it's created.

### CoreRedirects Lifecycle

1. **Add Entry**: Tool adds redirect on rename
2. **Runtime Resolution**: Engine resolves old names to new names on load
3. **Optional Cleanup**: After resaving all affected assets, redirect entry can be removed

## Blueprint Impact Analysis

### How It Works

The `BlueprintImpactAnalyzer` scans the project's Blueprint metadata to find:

1. **Direct Children**: Blueprints that directly inherit from the renamed class
2. **Indirect Children**: Blueprints that inherit from Blueprints that inherit from the renamed class

### Metadata Source

Blueprint metadata is stored in:
```text
{ProjectRoot}/Intermediate/NarshaMCP/metadata/blueprint_metadata.json.zst
```

If this file doesn't exist, the metadata will be auto-generated by narshamcp.exe. If it is still missing, run the commandlet manually:
```bash
# v7.0.0: Blueprint metadata is now auto-generated by narshamcp.exe
# If metadata is missing, run:
UnrealEditor-Cmd.exe <project>.uproject -run=NarshaMCP.MetadataCommandlet
```

### Impact Analysis Algorithm

```python
def analyze_class_rename(old_class_name: str, include_indirect: bool = True):
    impacts = []

    # Find direct children
    for bp in all_blueprints:
        if bp.parent_class == old_class_name:
            impacts.append(BlueprintImpact(
                blueprint_name=bp.name,
                parent_class=old_class_name,
                impact_reason="Direct child of renamed class"
            ))

    # Find indirect children (recursive)
    if include_indirect:
        affected_bps = [i.blueprint_name for i in impacts]
        for bp in all_blueprints:
            if bp.parent_class in affected_bps:
                impacts.append(BlueprintImpact(
                    blueprint_name=bp.name,
                    parent_class=bp.parent_class,
                    impact_reason="Indirect child (grandchild+)"
                ))

    return impacts
```

## Rust Integration

### ClassRenamer Rust Bindings

The file search operations use Rust for performance:

```python
from rust_indexer import RustClassRenamer

class ClassRenamer:
    def __init__(self, project_root: Path):
        self._rust_renamer = RustClassRenamer(str(project_root))

    def _find_class_files(self, class_name: str):
        # Rust parallel file search
        return self._rust_renamer.find_class_files(class_name)

    def _find_files_with_include(self, header_name: str):
        # Rust parallel grep
        return self._rust_renamer.find_files_with_include(header_name)
```

### Performance Comparison

| Operation | Python | Rust | Speedup |
|-----------|--------|------|---------|
| Find class files (500 files) | 3.2s | 0.1s | 32x |
| Find includes (500 files) | 5.4s | 0.3s | 18x |
| Find forward decls (500 files) | 4.1s | 0.2s | 20x |
| **Total** | **12.7s** | **0.6s** | **21x** |

## File Modification Details

### Header File Updates

**Before**:
```cpp
// ALCPlayerController.h
#pragma once
#include "CoreMinimal.h"
#include "GameFramework/PlayerController.h"
#include "ALCPlayerController.generated.h"

UCLASS()
class MYGAME_API ALCPlayerController : public APlayerController
{
    GENERATED_BODY()
    // ...
};
```

**After**:
```cpp
// ALCNewController.h
#pragma once
#include "CoreMinimal.h"
#include "GameFramework/PlayerController.h"
#include "ALCNewController.generated.h"

UCLASS()
class MYGAME_API ALCNewController : public APlayerController
{
    GENERATED_BODY()
    // ...
};
```

### Include Directive Updates

**Before**:
```cpp
#include "Controllers/ALCPlayerController.h"
```

**After**:
```cpp
#include "Controllers/ALCNewController.h"
```

### Forward Declaration Updates

**Before**:
```cpp
class ALCPlayerController;
```

**After**:
```cpp
class ALCNewController;
```

## Project Regeneration

### UnrealVersionSelector.exe

After renaming files, Visual Studio project files must be regenerated:

```python
def regenerate_project(project_root: Path):
    uproject = next(project_root.glob("*.uproject"))

    # Find UnrealVersionSelector
    version_selector = find_unreal_version_selector()

    # Execute regeneration
    subprocess.run([
        str(version_selector),
        "/projectfiles",
        str(uproject)
    ], check=True)
```

### Alternative: Right-Click Method

If automated regeneration fails:
1. Right-click on `.uproject` file
2. Select "Generate Visual Studio project files"

## Error Codes

| Code | Meaning | Resolution |
|------|---------|------------|
| `ERR_CLASS_NOT_FOUND` | Class doesn't exist | Check spelling, use `search_symbols` |
| `ERR_FILE_CONFLICT` | Target name exists | Choose different name |
| `ERR_ACCESS_DENIED` | File locked | Close Editor/VS |
| `ERR_NO_SOURCE` | Blueprint-only project | Convert to C++ first |
| `ERR_METADATA_MISSING` | No Blueprint metadata | Run metadata commandlet |
